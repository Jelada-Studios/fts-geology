## Built on

- Minecraft Forge, and the MDK it ships with.
- Terralith and Tectonic, whose biomes the tectonic model reads rather than replaces.
- Flowing Fluids and Water Erosion, detected at runtime and deferred to when present.

None of these are dependencies. The mod runs on a bare Forge install and always will.
